Proyecto Smart Task

Este proyecto es un primer acercamiento a la programación en Java con consola, se creó una aplicación que permite al usuario administrar una lista de tareas, se presenta por consola un menú básico que permite seleccionar opciones a ejecutar (Crear una tarea, listar las tareas pendientes, completar una tarea, listar las tareas completadas, eliminar tareas y salir del programa).
Se utiliza el paradigma de la Programación Orientada a Objetos para crear las Clases Tarea, Tarea Normal y Tarea Urgente para manejar priorizaciones entre ellas y crear todos los métodos correspondientes para que el proyecto funcione. Proyecto Biblioteca Untec

Este proyecto es un primer acercamiento a la programación en J2EE, se utilizó el patrón Modelo Vista Controlador para desarrollar una aplicación Web dinámica básica con Servlets como Controladores, JSP como Vistas y toda la capa de conexión a base de datos las Clases utilizadas y reglas de validaciones como Modelo.
La aplicación cuenta con básicas medidas de seguridad basado en un Login de acceso y manejo de roles dentro de la aplicación que permiten ser un Usuario que consulta la aplicación o un Administrador que puede gestionar el contenido de la página Web que consta de un Catálogo de Libros, se pueden agregar, modificar o eliminar libros del catálogo y se puede filtrar el catálogo gracias a una barra de búsqueda que permite filtrar por nombre, autor o editorial del Libro. Se utiliza el paradigma de la Programación Orientada a Objetos para crear las Clases Libro y Usuario para crear todos los métodos correspondientes para que el proyecto funcione y tenga los distintos roles dentro de la aplicación.
La aplicación está conectada a una Base de Datos MySQL en donde se almacenan las credenciales de los Usuarios permitidos para que accedan a la aplicación y toda la información de los libros del catálogo. Además la aplicación cuenta con su documentación hecha con JavaDoc, se puede consoltar el código fuente y su documentación en

Proyecto Academia Almazán

Este proyecto es un primer acercamiento a la programación en J2EE con el Framework de SpringBoot, se utilizó el patrón Modelo Vista Controlador gracias a Spring MVC para desarrollar una aplicación Web dinámica básica, se utilizó Spring Data JPA para la conexión y gestión de la Base de Datos MySQL, Thymeleaf y Spring Security para la seguridad del proyecto, que consta de un Login con roles dentro de la aplicación y tambipen cuenta con Hashing de contraseñas al momento de almacenarlas en la Base de Datos. Además se utilizó el Repositorio Maven para gestionar las dependencias de nuestra aplicación.
El manejo de roles dentro de la aplicación nos permiten ser un Usuario que consulta la aplicación o un Administrador que puede gestionar el contenido de la página Web que consta de un Catálogo de Cursos, y a cada Curso se le pueden asignar Estudiantes. Se pueden agregar, modificar o eliminar cursos del catálogo y se puede filtrar el catálogo gracias a una barra de búsqueda que permite filtrar por ciertos atributos y podemos ver el detalle de cada Curso. Además es posible asignar Alumnos a cada Curso, se puede modificar y eliminar la información de los Estudiantes y utilizar la barra de búsqueda para filtar la lista de estudiantes y ver el detalle de cada uno de ellos.
Se utiliza el paradigma de la Programación Orientada a Objetos para crear las Clases Curso, Estudiante y Usuario para crear todos los métodos correspondientes para que el proyecto funcione y tenga los distintos roles dentro de la aplicación. La aplicación permite la creación de Usuarios y Administradores para manejar la página Web, todos los datos de Usuarios, Cursos y Estudiantes quedan guardados en la Base de Datos.
